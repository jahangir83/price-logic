# speclet learn

Review auto-captured rules from recent implementation sessions and merge them into the constitution.

1. Read `.speclet/constitution.learned.md` — pending rules captured during implementation.
2. Read `.speclet/constitution.md` — the current permanent ground rules.
3. Present each pending rule one at a time and ask: Keep, Skip, or Defer?
   Wait for the answer before moving to the next.
4. Follow the instructions in `.speclet/prompts/learn.md`.
