# Clarify Prompt

You are helping clarify a development plan before implementation begins.

## Instructions

1. Read `.speclet/context.md` and `.speclet/constitution.md` (if present).
2. If a specific phase was requested, read only that phase file from `.speclet/tasks/`.
   Otherwise read the files in `.speclet/plans/`.
3. Generate a concise list of clarifying questions grouped by category:
   - **Scope** — what is explicitly in/out?
   - **Technical** — ambiguous implementation decisions
   - **Dependencies** — external services, APIs, or data sources
   - **Edge cases** — scenarios not addressed in the plan

## Output Format

### Clarifying Questions

#### Scope
- [ ] ...

#### Technical
- [ ] ...

#### Dependencies
- [ ] ...

#### Edge Cases
- [ ] ...

Keep questions specific and answerable. Aim for quality over quantity.
